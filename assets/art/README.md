# Painted art slots

Drop painted art here and the game picks it up with no code changes:

- `title_bg.png`: full-bleed title key art (portrait, 1080x1920 or larger). When present it replaces the live sea behind the title.

More slots (ship sprite layers, island/cliff/reef tiles, event illustrations, UI frames) are
proposed in docs/ART-PIPELINE.md and are not wired up yet.
